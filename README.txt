
Instruções para rodar a landing page Publi X:

1. Baixe o arquivo ZIP e extraia em uma pasta.
2. Abra o arquivo landing-publi-x.html em qualquer navegador.
3. Para edição, modifique o arquivo HTML, CSS ou JS conforme necessidade.
4. Para publicação, suba os arquivos extraídos para seu servidor ou serviço de hospedagem.

Pronto! Sua landing page estará no ar.
